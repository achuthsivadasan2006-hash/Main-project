📚 Study Tracker – Student Study Management System

A web-based application designed to help students organize their studies, manage tasks, set deadlines, and track their academic progress in one place.

🌐 Live Practice

Website: "Study Tracker" (https://achuthsivadasan2006-hash.github.io/Main-project/)

GitHub Repository: "Main-project" (https://github.com/achuthsivadasan2006-hash/Main-project)

🎯 Objectives

- Organize subjects and study tasks.
- Create, edit, and delete tasks.
- Set deadlines and priorities.
- Track completed and pending tasks.
- Monitor study progress.
- Improve time management and productivity.

✨ Features

- Task Management: Add, update, complete, and delete tasks.
- Subject Organization: Organize study activities by subject.
- Progress Tracking: Monitor task completion and study progress.
- Deadline Management: Keep track of upcoming tasks.
- User-Friendly Interface: Simple and easy-to-use design.

🛠️ Technologies Used

- HTML – Web page structure
- CSS – Styling and layout
- JavaScript – Functionality and interactivity
- Git and GitHub – Version control and project hosting
- GitHub Pages – Website deployment

🚀 Getting Started

Run Locally

1. Clone the repository:
   
   git clone https://github.com/achuthsivadasan2006-hash/Main-project.git

2. Open the project folder.

3. Open "index.html" in your web browser.

Alternatively, open the live website using the link provided above.

⚙️ System Requirements

- A computer or smartphone
- A modern web browser
- Internet connection for accessing the hosted website
